SISTEM INFORMASI LAYANAN KESEHATAN EVAKUASI PASIEN (SIYANKES)

Versi Sistem: 2.6.7 | Edisi: Militer / Operasional Aktif

RINGKASAN EKSEKUTIF: Dokumen panduan resmi ini mencakup petunjuk operasional, kebijakan hak akses, aturan nomor surat unik, serta Prosedur Penghapusan (Delete) Akun Pengguna untuk seluruh tingkatan akun di dalam sistem SIYANKES Kesdam XVII/Cenderawasih.

I. PANDUAN MENJALANKAN APLIKASI

  1. Akses Alamat Aplikasi: Buka peramban web (Google Chrome / Mozilla Firefox) pada PC, Tablet, atau Smartphone, lalu akses URL sistem yang telah dibagikan (Dev/Production URL).
  2. Mode Tamu (View-Only): Pengguna umum atau tamu dapat langsung melihat dashboard, statistik rekam medis evakuasi, dan grafik secara real-time tanpa perlu melakukan login.
  3. Masuk ke Akun (Login):
    • Klik tombol [ MASUK ] di sudut kanan atas navbar.
    • Masukkan Username dan Password akun Anda.
    • Contoh Akun Super Admin Utama: Username hendra | Password 101110.
  4. Sinkronisasi & Real-Time Data:
    • Sistem secara otomatis memantau pembaruan data spreadsheet setiap 2 detik di latar belakang.
    • Gunakan tombol [ Sinkron ] di bilah atas untuk memperbarui data rekam medis secara instan kapan saja.

III. PANDUAN PENGHAPUSAN (DELETE) AKUN PENGGUNA

Penghapusan akun operator atau tamu di dalam sistem diatur dengan ketentuan keamanan yang ketat:

  1. Hak Akses Hapus Akun: Hanya Super Admin Utama (akun hendra) yang memiliki kewenangan untuk mengakses menu "Tambah Akun & Hak Akses" dan melakukan penghapusan akun. Operator dan Tamu tidak memiliki akses ke menu ini.
  2. Langkah-langkah Menghapus Akun:
    • Masuk ke sistem menggunakan akun Super Admin (hendra / Password: 101110).
    • Pada bilah navigasi atas, klik tombol emas [ Tambah Akun & Hak Akses ].
    • Pada daftar akun terdaftar, cari nama pengguna atau operator yang ingin dihapus.
    • Klik tombol ikon tempat sampah berwarna merah [ Hapus / Delete ] pada baris akun tersebut.
    • Konfirmasi peringatan dialog sistem. Akun akan langsung dihapus permanen dari server dan disk sistem.
  3. Ketentuan Perlindungan Akun Utama: Akun Super Admin utama (hendra) dilindungi oleh sistem dan tidak dapat dihapus untuk mencegah kehilangan akses administratif penuh terhadap sistem.

IV. ATURAN KETAT NOMOR SURAT (ANTI-DUPLIKASI)

PERHATIAN KRITIS: Berdasarkan kebijakan operasional tertib administrasi Kesdam XVII/Cenderawasih:
  • Nomor Surat (srt) WAJIB UNIK: Sistem mendeteksi nomor surat secara otomatis.
  • Apabila ditemukan nomor surat yang ganda/double, sistem secara otomatis MEMBLOKIR proses pengiriman data baru, penyimpanan, unduh berkas (*download*), dan pencetakan surat (*print*).
  • Pastikan setiap pengajuan surat evakuasi baru memiliki nomor urut surat dinas yang berbeda (contoh: B/83/EV/2026).
